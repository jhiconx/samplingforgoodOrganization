# Sampling For Good Shopper

GitHub repository suggestion: samplingforgood-shopper

Upload public/, vercel.json, and README.md to the repository root. In Vercel, import the repository. Framework: Other. Output directory: public. No build command or dependency installation is required.

Four-screen PWA:
1. Make-A-Wish sampling introduction and swipe entry.
2. Offer wall with 13 selectable illustrative brands and Enter button.
3. Iconx AI styled planning page: selected brands, optional prompt, requested shipping date, quantity per brand, and sponsor confirmation.
4. Summary with Swipe to Sample and Give and a clearly labeled demo completion state.

The three additional demo brands are Poppi, e.l.f., and Starface. The catalog uses the supplied imagery plus text treatments; it does not assert confirmed offers or partnerships.

Status: interactive frontend review demo. AI generation, inventory, shipment booking, user accounts, persistent orders, donation processing, and sponsor verification are not connected. No shipment or donation is submitted. The $1 weekly giving message is user-supplied campaign copy, not a verified operational program. Quantities are requested per selected brand; digital offers are labeled separately in the summary. No donation total is inferred from quantities.

PWA manifest and service worker cache local app assets. Google Fonts is optional online typography; system fonts are the offline fallback. Installability varies by browser. Serve over HTTPS or localhost, not file://.
